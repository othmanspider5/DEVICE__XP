INSTALL / UPDATE ON GITHUB PAGES
1. Open your DEVICE_X GitHub repository.
2. Open the repository root (the page showing the files).
3. Upload these three files directly into the root, replacing the old files.
   Do not upload the folder DEVICE_X_PRO_FIXED itself.
4. Commit the changes to the main branch.
5. Wait for GitHub Pages to redeploy, then refresh your public website.

IMPORTANT
- The search field is active immediately and supports typing, filtering, clearing, and keyboard selection.
- The app attempts to load up to 500 smartphone rows and 300 laptop rows from public community CSV datasets.
- If either dataset is unavailable or blocked, built-in sample records are shown so the page remains usable.
- This is not an official manufacturer-certified database. Public dataset fields can be incomplete, inconsistent, or configuration-dependent. Verify specifications with the manufacturer before buying.
- The app requires internet for remote datasets and Google Fonts. The built-in sample records still work if the datasets fail.
- No claim is made that every device has a verified photo; this build intentionally avoids misleading or mismatched stock photos.
- The app does not impose a search limit. The visible “Load more devices” button reveals additional matching records in batches.
